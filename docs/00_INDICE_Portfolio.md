# Portfolio — Índice

Portefólio técnico pessoal de Alexandre Chainho, publicado como site estático
em [alexchainho.github.io](https://alexchainho.github.io/), em três idiomas
(PT/EN/FR), com exportação para PDF.

## Stack

- HTML/CSS/JS puro (sem framework) para o site publicado.
- Node.js + Playwright (`playwright-core`, Chrome do sistema) para o script
  de exportação em `tools/`.
- GitHub Pages (hosting estático) + Cloudflare Web Analytics (medição, sem
  cookies).
